# StockPicker.gg

## Fastest way to get a live link

1. Create a new GitHub repo named `stockpicker-gg`.
2. Upload `app.py`, `requirements.txt`, and `README.md`.
3. Go to Streamlit Community Cloud and connect the repo.
4. Deploy the app.

Streamlit will generate a public URL like `https://your-app-name.streamlit.app`.
